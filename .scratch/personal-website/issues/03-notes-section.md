# 03: 「笔记」栏目端到端

**What to build:** 作者可以发表技术学习笔记，朋友浏览时能清楚区分两类笔记。笔记作为独立栏目，在导航中位置弱于随感；列表页按「读书技术笔记」与「专题学习笔记」分组；每篇笔记有 `/notes/:slug/` 稳定链接，读书笔记可体现书名。

**作者需提供素材：** 读书、专题各 1 篇现成笔记（如《凤凰架构》笔记、Reactor 或 MongoDB 笔记；纯文本可由实施方转 Markdown）。若暂不提供，先用占位内容，但上线前需替换为真实内容。

**Blocked by:** 01（站点骨架与自动部署管线）；排版约定与票据 02 一致，可与 02 并行
