# 05: 「摄影」栏目与灯箱端到端

**What to build:** 朋友进入摄影栏目，看到按时间倒序的相册封面网格；点开相册看到说明与整组照片；点击任意照片进入全屏灯箱，可左右切换、键盘/手势操作、ESC 退出，看到 2000px 大图，光圈/快门/ISO 在图上以清晰可读的大小叠加；作者提供的 caption 展示在照片下方或侧边，没有 caption 时画面干净。页面懒加载，不一次拉取全部图片。图片 URL 由统一前缀拼接，未来可零改动切 COS/TOS。

**作者需提供素材：** 第 1 个真实相册 10–20 张原片，给出相册标题/年份/说明、若干张照片的 caption、指定封面；再提供第 2 个小相册 5–8 张原片（用于首页混合流与摄影网格的真实效果，可为一次旅行相册）。

**Blocked by:** 01（站点骨架与自动部署管线）、04（图片处理脚本与数据契约）

**Status:** ready-for-agent

- [ ] albums collection 生效，永久链接为 `/photography/:slug/`（年度如 `2025`，旅行如 `kyoto-2019`）
- [ ] 摄影首页为封面网格：封面 + 标题 + 年份，按时间倒序
- [ ] 相册页含简短说明与懒加载照片网格
- [ ] PhotoSwipe 灯箱支持左右切换、键盘、手势、ESC/点遮罩退出
- [ ] 灯箱加载 2000px 大图
- [ ] 光圈、快门、ISO 在灯箱图片上以有一定大小、清晰可读的方式叠加
- [ ] caption 可选，展示在照片下方或侧边；无 caption 时不占位；不设地点字段
- [ ] `image_cdn` 配置默认为空，所有照片 URL 由前缀 + 相对路径构成，改前缀即可切换图片托管
- [ ] 2 个真实相册（脚本生成产物）本地与线上可完整浏览
